# Smart Boiler Control & Monitoring System

An embedded control system powered by an **ATmega** microcontroller, designed for real-time monitoring and automation of pellet, wood, and multi-fuel heating boilers.

### Key Features
* **Multi-Fuel Support**: Optimized for pellet and traditional wood combustion systems.
* **Automated Control**: Smart management of heating parameters and fuel supply.
* **Universal Compatibility**: Adaptable monitoring solution intended for various boiler types.
